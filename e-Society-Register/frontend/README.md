# Web frontend

See [the project README](../README.md) for environment setup, role accounts, and the end-to-end demo. This React/Vite app uses `VITE_API_URL` for the REST API and Socket.IO. Install with `npm ci`, start with `npm run dev -- --strictPort`, and check TypeScript and the production bundle with `npm run build`. QR camera access requires HTTPS or localhost.
